# MLX Node Parity Features

This document lists the features of the MLX Python API that are targeted for parity in the Node.js implementation.
For an accurate assessment of current porting status and drift from the Python implementation, refer to the `ast_distance` reports generated by ProjectHub.

## Core Infrastructure
- Build native addon (`mlx_array.node`) via N-API with MLX core sources.
- Shared build configuration for additional MLX sources (ops, evaluators, transforms).

## DType Surface (`mlx.core.dtype`)
- MLX dtype constants with key/size/category accessors.
- Native `mlx::core::issubdtype` helpers.
- Dtype category enums and `issubdtype` parity helpers.
- Python-parity formatting and introspection.

## Array Constructors (`mlx.core.array`)
- Instantiate arrays from host buffers.
- Zero-copy/unified-memory backed constructors.
- Scalar and shape utilities (broadcasting, `zeros_like`, `ones_like`).

## Array Operations
- Structural ops: `reshape`, `transpose`, `swapaxes`, `moveaxis`.
- Indexing and slicing semantics consistent with MLX.
- Arithmetic and comparison ops leveraging MLX primitives.
- Gradient and autodiff compatibility.

## React/Next Integration
- React 19/Next.js friendly wrappers for server components.
- Hydration-safe patterns for shared memory contexts.

## Memory & Performance
- Unified allocator entry points.
- Cache and memory limit controls.
- Performance benchmarking for parity with Python.

## I/O & Model Loading
- GGUF and safetensors loaders.
- Metal runtime and kernel initialization.
- Automated metallib generation.

## Optimizers (`mlx.optimizers`)
- Base `Optimizer` class with tree-based parameter handling.
- Implementation of standard optimizers (SGD, Adam, Adamax, Lion, RMSprop, AdamW, Adagrad, AdaDelta, Adafactor).
- Scheduler support.

## Neural Network (`mlx.nn`)
- Random number generation (normal, uniform).
- Initializers (constant, glorot, he, orthogonal, sparse).
- Layer implementations and activation functions.

## Tooling & Tests
- TypeScript test harness.
- Optimizer validation and integration tests.
- Regression tests for dtype and array interop.
